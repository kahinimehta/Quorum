Dashboard

Interactive UI for pipeline runs, KPIs, ranked treatments, synthetic cohort, and agent trace.

Not hosted on GitHub Pages. The dashboard is a local app (HTML + Python API). Clone the repo and run it on your machine.

One-command start

cd neurodiscover
pip install -r requirements.txt
cp .env.example .env   # optional: SUPABASE_DATABASE_URL
make dashboard
  • Dashboard UI: http://127.0.0.1:8080
  • API: http://127.0.0.1:5000
  • Source: neurodiscover/frontend/index.html

What you can do

  • Step 1 — Run demo, incremental scan, or full pipeline with max_papers
  • Step 2 — View ranked recommendations, hypotheses, evidence table, synthetic patients
  • Recent runs — Click a run to see Complete vs Partial with agent counts (e.g. 3/6)
