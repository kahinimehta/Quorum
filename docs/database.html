Database

SQLite locally or Supabase Postgres for the team — table evidence, not papers.

Core tables

TableRole
evidenceOne row per source (literature, trial, grant)
subgroupsPatient subgroups discovered from evidence
treatment_connectionsSubgroup → mechanism → treatment + scores
recommendationsFinal ranked outputs per run
agent_outputsAppend-only agent trace (run_id)
subgroup_evidence, connection_evidenceMany-to-many links

Evidence row highlights

  • source_type — literature | trial | grant
  • source_id — PMID, NCT id, or grant id (never invented)
  • access_type — published_oa, published_paywalled, preprint
  • Unique on (source_type, source_id) for dedup on re-pull
