Architecture decisions

Why we built NeuroDiscover this way — contracts the whole team shares.

SQLite / Postgres, not MongoDB

Early docs mentioned MongoDB papers. The contract is SQL table evidence with FK integrity, via Supabase or local neurodiscover.db.

Database as blackboard

Agents do not call each other directly. They read/write tables so API, agents, and dashboard evolve independently.

No cli.py build on live Supabase

Live DB: Team Supabase already has 300+ real rows. build truncates all tables. Use scan / pull only.

Vanilla dashboard + FastAPI

Single index.html and api_server.py avoid build tooling for demos. Default path is API-only (no browser secrets).

Synthetic cohort not persisted

Patient profiles are generated per run_id, labeled synthetic/no PHI, and never stored.

External tools

  • BioMCP — unified PubMed + ClinicalTrials.gov
  • Nebius / Ollama — structured extraction (EXTRACT_BACKEND)
  • Tavily / NIH RePORTER — commercial agent signals
