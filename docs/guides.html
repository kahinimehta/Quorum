GitHub Pages — neurodiscover.github.io

The URL https://neurodiscover.github.io is the root site for the GitHub account or organization named neurodiscover. It is not the same as https://kahinimehta.github.io/Quorum/ (project Pages).

Step 1 — Create the org site repo

  1. Create a GitHub organization (or user) named neurodiscover.
  2. Create a public repository named exactly neurodiscover.github.io.
  3. In that repo: Settings → Pages → Build and deployment → Source: GitHub Actions.

Step 2 — Deploy this docs/ folder (automated)

  1. In neurodiscover.github.io repo settings, add secret NEURODISCOVER_PAGES_TOKEN — a fine-grained PAT with Contents: Read and write on that repo only.
  2. In Quorum repo settings, add the same secret name so Actions can push docs.
  3. On Quorum: run workflow Deploy docs to neurodiscover.github.io (or push to main after merge).

Workflow: .github/workflows/deploy-neurodiscover-org-pages.yml

Alternative — interim project URL

Until the org site exists, use Quorum project Pages:

  1. Settings → Pages → Source: GitHub Actions on kahinimehta/Quorum.
  2. Disable or remove the default Jekyll workflow if it conflicts; use Deploy documentation to GitHub Pages (deploy-docs.yml).
  3. Site URL: https://kahinimehta.github.io/Quorum/ (sidebar links auto-detect this path).
