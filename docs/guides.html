GitHub Pages (team docs site)

Static pages live in docs/ (overview, workflow, team, guides). The dashboard itself still runs locally via make dashboard — it is not hosted on Pages.

Option A — GitHub Actions (recommended)

  1. Merge to main and git pull origin main.
  2. On GitHub: Settings → Pages → Build and deployment → Source: GitHub Actions.
  3. Push to main (or run the workflow manually: Actions → “Deploy documentation to GitHub Pages” → Run workflow).
  4. When the job succeeds, open the environment URL shown on the run (usually https://<org>.github.io/<repo>/).

Workflow file: .github/workflows/deploy-docs.yml (uploads the docs/ folder).

Option B — Deploy from branch

  1. Settings → Pages → Source: Deploy from a branch.
  2. Branch main, folder /docs, Save.
  3. Wait ~1–2 minutes; the Pages URL appears at the top of the same settings page.

Use only one option (Actions or branch deploy). If both are enabled, prefer Actions so deploys match CI.

First-time setup: the repo needs Pages enabled on the free plan; no extra secrets are required for the docs workflow.
