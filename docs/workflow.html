Workflow

Six agents run in order. Each reads prior tables and writes its own — the database is the blackboard.

Pipeline (in order)

① Literature → ② Subgroups → ③ Connections → ④ Evidence score → ⑤ Commercial → ⑥ Conclusions
AgentReadsWrites
Literature SynthesisPubMed, bioRxiv, ClinicalTrials.gov, NIH RePORTERevidence, subgroup_evidence, scan_state

Evidence Scoringconnections + evidenceevidence_strength, agent_outputs

Conclusion Updatescored connectionsrecommendations

Run modes

  • Demo (offline) — Uses seeded evidence; respects max_papers for downstream agents. Safe on stage.
  • Incremental scan — Adds literature via BioMCP; skips LLM for known source_ids.
  • Full pipeline — Live pull + optional grants when network and keys are ready.

Every run shares one run_id in agent_outputs for audit and dashboard filtering.

Run status

Complete — all six agents logged for the run_id and at least one recommendation exists.

Partial — stopped early (missing agents or no recommendations). The dashboard shows how many agents ran (e.g. 3/6), not ?/6.

Dashboard outputs

  • Synthetic cohort — Patients A–E (ephemeral, not in DB)
  • Ranked treatments — confidence bars and recommendation cards
  • Research hypotheses — auditable proposals with citation links
  • Agent trace + evidence table — provenance for judges
